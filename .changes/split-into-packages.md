## Release Note
Controller Editor and Avatar Dynamics Overhaul are now separate packages
Install only the tool you use. Both appear in the Creator Companion as their own packages, and the code they share comes along automatically as a third package.

## Notices
- important: If your project has DreadScripts - Unlocked 0.1.0, add Controller Editor, Avatar Dynamics Overhaul or both from the Creator Companion. Installing either removes the old combined package.
